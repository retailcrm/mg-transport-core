# mg-transport-core documentation

`mg-transport-core` is a Go library with the shared building blocks used to create [Message Gateway]
transports: an application engine with configuration, logging, localization, error reporting and
background jobs; typed job queues with autoscaling worker pools; typed caches; HTTP client utilities;
database migrations; and CLI tooling.

A *transport* is a service that connects the RetailCRM Message Gateway to a messaging channel
(WhatsApp, Telegram, email, and so on). Transports built on this library share the same operational
behavior, configuration format, and deployment shape, which keeps them predictable to operate and fast
to develop.

```
module github.com/retailcrm/mg-transport-core/v2
```

## Quick start

A minimal transport application:

```go
package main

import (
	"fmt"
	"html/template"
	"os"

	"github.com/gin-gonic/gin"
	"github.com/retailcrm/mg-transport-core/v2/core"
)

func main() {
	app := core.New(core.AppInfo{
		Version:   "v1.0",
		Commit:    "bcef82e",
		Build:     "v1.0-bcef82e",
		BuildDate: "1649766442",
	})

	app.Config = core.NewConfig("config.yml")
	app.DefaultError = "unknown_error"
	app.TranslationsPath = "./translations"
	app.PreloadLanguages = core.DefaultLanguages

	app.ConfigureRouter(func(engine *gin.Engine) {
		engine.HTMLRender = app.CreateRenderer(
			func(renderer *core.Renderer) {
				renderer.Push("home", "templates/layout.html", "templates/home.html")
			},
			template.FuncMap{},
		)
	})

	if err := app.Prepare().Run(); err != nil {
		fmt.Printf("Fatal error: %s", err.Error())
		os.Exit(1)
	}
}
```

From here, transports typically add:

- background processing with [`core/queue`](queues.md),
- request-scoped caching with [`core/cache`](cache.md),
- cross-instance coordination through [NATS](nats.md),
- periodic jobs via the [JobManager](engine.md#job-manager),
- and migrations generated by [`transport-core-tool`](packages.md#cmdtransport-core-tool).

## Installation

```sh
go get github.com/retailcrm/mg-transport-core/v2
```

The library targets the Go version declared in its `go.mod` (currently Go 1.27). API reference is
published on [pkg.go.dev].
